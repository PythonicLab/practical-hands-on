## Come eseguirli

Serve Python 3.

- **Windows**:
  ```cmd
  python esercizio_001.py
  ```

- **Linux**:
  ```bash
  python3 esercizio_001.py
  ```

- **macOS**:
  ```bash
  python3 esercizio_001.py
  ```

Molti esercizi chiedono un input da tastiera.

I file `.project` e `.pydevproject` sono la configurazione di Eclipse con PyDev, l'IDE, e per eseguire gli script non servono.
